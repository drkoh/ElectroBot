# ⚡ ElectroBot v2.0 — Моніторинг відключень світла (Харків та область)

Сучасний настільний інженерний додаток у стилі **Microsoft Fluent 2 / Modern Office** для відстеження реального стану електропостачання, оперативних аварійних робіт та графіків погодинних відключень (ГПВ) у Харкові.

---

## 🎯 Ключові можливості версії 2.0

- **🚨 Розумний пріоритетний резолвер стану (Smart State Resolver):**
  - Об'єднує 3 незалежні рівні інформації:
    1. **Міська диспетчерська АСДС «1562»:** фактичні аварійні знеструмлення за конкретною вулицею та номером будинку з точним прогнозованим часом відновлення.
    2. **Спеціальні графіки аварійних відключень (ГАВ):** термінові розпорядження НЕК «Укренерго» при масованих атаках з офіційного Telegram-каналу.
    3. **Погодинні планові графіки (ГПВ):** добовий розклад по 12 підчергах (`1.1` – `6.2`).
  - Статус більше ніколи не показує помилкове «Світло є», якщо на вашій підстанції діє аварія!

- **⚡ Помічник підготовки («Вікно для зарядки»):**
  - Розраховує, скільки годин електроенергія гарантовано подаватиметься: *«Вікно зарядки: ~3 год 15 хв (до 15:30)»*. Допомагає вчасно зарядити ноутбуки, павербанки та зарядні станції EcoFlow.

- **📡 Фізичний детектор світла (Router Ping Checker):**
  - Пінгує домашній роутер або локальний шлюз (`192.168.1.1` або автовизначений шлюз) у фоновому режимі без консольних вікон (`CREATE_NO_WINDOW`).
  - Якщо роутер не відповідає — сигналізує про фізичне зникнення живлення в оселі.

- **📌 Плаваючий міні-віджет (Compact Floating Bar):**
  - Компактна панель у кутку робочого столу в режимі Always-on-Top:
    `[ ⚡ Черга 2.1 | 🔴 Аварія 1562 | ⏳ 09:42:15 ]`.
  - Легко перетягується мишею, дозволяє відкрити головне вікно в 1 клік.

- **🚀 60 FPS неблокуючий асинхронний рушій (`QThreadPool` + `QRunnable`):**
  - Усі мережеві запити (Telegram, 1562, пінг роутера) виконуються паралельно у фонових потоках. Інтерфейс залишається плавним і ніколи не зависає *(Not Responding)*.

- **🔍 Точний парсер вулиць та будинків:**
  - База містить усі 3291 офіційні вулиці Харкова.
  - Точне розпізнавання номерів (`4/6`, `10-А`, `15`) запобігає хибним спрацьовуванням для сусідніх будинків.

## 🚀 Запуск додатку

### 💻 Windows Desktop:
1. **Головний запуск (без консолі, Zero-Console):**
   Двічі клікніть на **`ElectroBot.exe`**
2. **Альтернативний запуск:**
   Двічі клікніть на **`Launch_ElectroBot.bat`** або виконайте у терміналі:
   ```powershell
   python run.py
   ```

### 📱 Android Mobile:
Готовий інсталяційний файл зібрано в корені репозиторію:
👉 **`ElectroBot-v1.0-mobile.apk`** (12.2 МБ)

Встановити на телефон можна будь-яким зручним способом:
- **Через USB (ADB):**
  ```powershell
  adb install -r ElectroBot-v1.0-mobile.apk
  ```
- **Прямим надсиланням:** перетягніть `ElectroBot-v1.0-mobile.apk` собі у «Збережене» (Saved Messages) у Telegram або завантажте через Google Drive / кабель на телефон і натисніть «Встановити».
